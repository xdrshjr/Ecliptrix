# Spec 05: 交互增强与动画系统

## 目标

为时间轴式对话 UI 添加精细的交互动画和视觉反馈，提升操作状态感知、展开/收起流畅性、以及整体交互品质。

## 设计方案

### 1. 节点状态动画

#### 节点出现动画

新节点进入时间轴时的入场动画：

```
// 动画规格
初始状态: opacity: 0, translateY: 10px
结束状态: opacity: 1, translateY: 0
时长: 200ms
缓动: ease-out
```

使用 framer-motion 的 AnimatePresence + motion.div 实现，确保列表中新增/移除节点的动画平滑。

#### 节点图标状态转换

| 状态 | 图标 | 动画 |
|------|------|------|
| 用户消息 | 实心圆（主题色） | 无（静态） |
| AI 思考中 | 半圆 | 持续旋转（spin 1s linear infinite） |
| 执行中 | 同心圆 | 脉冲缩放（pulse: scale 1→1.2→1, 1.5s） |
| 执行完成 | 绿色对勾圆 | 从同心圆过渡到对勾（300ms） |
| 执行失败 | 红色叉圆 | 从同心圆过渡到叉号 + 轻微shake（300ms） |
| 已撤销 | 灰色圆 | 从原状态褪色（200ms） |

#### 连接线动画

执行中节点到下一个节点之间的连接线使用渐变色 + 流动效果：

```css
/* 伪代码 — 执行中区间的连接线 */
.timeline-connector--active {
  background: linear-gradient(
    180deg,
    var(--primary) 0%,
    var(--primary-light) 50%,
    transparent 100%
  );
  background-size: 100% 200%;
  animation: flow 2s ease-in-out infinite;
}

@keyframes flow {
  0% { background-position: 0% 0%; }
  100% { background-position: 0% 100%; }
}
```

### 2. ToolStep 交互动画

#### 展开/收起

使用 framer-motion 的 `AnimatePresence` + `motion.div` 的 `layout` 属性：

```
// 收起状态
┌──────────────────────────┐
│ ✅ 裁剪片段  0.3s        │  ← 单行摘要
└──────────────────────────┘

// 展开状态（高度过渡 200ms）
┌──────────────────────────┐
│ ✅ 裁剪片段  0.3s        │
│ ─────────────────────── │
│ 参数:                    │
│   clipId: "clip-1"       │
│   startTime: 0           │
│   endTime: 5             │
│ 结果:                    │
│   裁剪完成，新时长 5.0s   │
└──────────────────────────┘
```

动画规格:
- 高度过渡: 200ms, ease-out
- 内容淡入: 150ms, 延迟 50ms
- 旋转箭头指示器: 180° 旋转, 200ms

#### 执行中进度

ToolStep 处于 executing 状态时的视觉反馈：

1. **加载指示器**: 工具名称旁显示旋转图标（使用 Tailwind 的 animate-spin）
2. **背景脉冲**: 卡片背景轻微脉冲（opacity 0.05 → 0.1 → 0.05）
3. **耗时计时器**: 实时显示执行耗时（"0.3s", "1.2s", ...），使用 setInterval 每 100ms 更新

#### 完成/失败转换

```
executing → completed:
  1. 旋转图标 → 对勾图标（scale 0→1, 200ms, spring）
  2. 背景闪绿（opacity 0→0.1→0, 300ms）
  3. 耗时计时器冻结

executing → error:
  1. 旋转图标 → 叉号图标（scale 0→1, 200ms）
  2. 背景闪红（opacity 0→0.15→0.05, 300ms），保持浅红背景
  3. 错误信息滑入（translateY -5→0, opacity 0→1, 200ms）
  4. shake 动画（translateX: 0→-3→3→-2→2→0, 300ms）
```

### 3. 撤销交互

#### 撤销按钮

- 位于 AgentResponseNode 底部
- "撤销全部" 按钮 + 单个操作的下拉撤销菜单
- Hover 时显示撤销预览提示（tooltip: "将恢复到操作前的状态"）

#### 撤销动画

```
1. 被撤销的 ToolStep:
   - 背景变灰（200ms）
   - 添加删除线效果
   - opacity 降至 0.5

2. 被撤销的 ExecutionNode:
   - 整体变灰
   - 节点图标变为灰色回退图标

3. 时间轴连接线:
   - 撤销区间的连接线变为灰色虚线
```

### 4. 取消执行交互

执行中显示取消按钮：

```
┌─────────────────────────────┐
│ ◉ 执行操作 (1/3)            │
│ ┌─────────────────────────┐ │
│ │ ✅ 获取时间轴            │ │
│ │ ⏳ 裁剪片段...           │ │
│ └─────────────────────────┘ │
│                             │
│       [ 取消执行 ]          │ ← 取消按钮
└─────────────────────────────┘
```

取消后动画:
1. 正在执行的 ToolStep 切换为灰色"已取消"状态
2. 后续未执行的步骤不显示
3. 节点图标变为灰色
4. 显示提示: "执行已取消，已完成的操作已保留"

### 5. 流式文本动画

Agent 文本响应的流式效果：

- 文字逐步出现时使用 cursor 脉冲（模拟打字光标）
- 最后一个字符后显示闪烁光标：`|` 脉冲动画（opacity 0→1→0, 800ms）
- 流结束后光标消失

### 7. 错误状态展示

Agent 级别错误（非工具级别）的展示：

```
┌─────────────────────────────┐
│ ⚠ 执行遇到问题              │
│                             │
│ 网络连接中断，正在重试...    │
│ 重试次数: 1/2               │
│ [████████░░] 等待重连        │
│                             │
│ [取消] [手动重试]            │
└─────────────────────────────┘
```

### 8. 暗色模式适配

所有动画和视觉效果需要适配暗色模式：

| 元素 | 亮色模式 | 暗色模式 |
|------|----------|----------|
| 时间轴连接线 | `border-gray-200` | `border-gray-700` |
| 活跃连接线 | `primary/20%` | `primary/30%` |
| 节点图标 | 主题色 | 主题色（不变） |
| ToolStep 背景 | `bg-gray-50` | `bg-gray-800` |
| 成功闪烁 | `bg-green-50` | `bg-green-900/20` |
| 错误闪烁 | `bg-red-50` | `bg-red-900/20` |
| 已撤销状态 | `opacity-50 bg-gray-100` | `opacity-50 bg-gray-800` |

## 验收标准

1. 所有节点状态转换有平滑动画（无突兀闪烁）
2. ToolStep 展开/收起动画流畅（无布局跳动）
3. 执行中状态有明确的视觉反馈（旋转图标+脉冲+计时器）
4. 取消按钮在执行中可见且可用
5. 暗色模式下所有动画效果正常
6. 空对话显示欢迎引导，建议可点击
7. 动画不影响滚动性能（使用 will-change/transform 优化）
8. 60fps 无卡顿（开发者工具 Performance 面板验证）

## 性能约束

- 动画使用 CSS transform 和 opacity（触发 GPU 合成，不触发 layout/paint）
- framer-motion 的 `layout` 属性仅用于需要布局动画的元素
- 长列表中已完成的节点不需要持续动画（停止动画释放资源）
- setInterval 计时器在 ToolStep 不可见时暂停（IntersectionObserver）
