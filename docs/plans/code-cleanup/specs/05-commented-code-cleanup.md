# Spec 05: 注释代码块全面清理

## 概述

扫描全项目所有源代码文件，找出并删除被注释掉的代码块。保留有价值的文档注释、TODO 注释和说明性注释。

## 区分标准

### 需要删除的（注释掉的代码）

- 被注释掉的函数/方法定义
- 被注释掉的 import 语句
- 被注释掉的变量赋值
- 被注释掉的 JSX/HTML 结构
- 被注释掉的条件分支
- 被注释掉的 API 调用
- `// old implementation`、`// previous version` 类标记的代码块

### 需要保留的（有价值的注释）

- 文档注释（JSDoc、docstring）
- TODO/FIXME/HACK/NOTE 注释
- 业务逻辑说明注释
- 配置说明注释
- 许可证/版权声明
- ESLint disable 注释（如 `// eslint-disable-next-line`）
- TypeScript 指令注释（如 `// @ts-ignore`）

## 扫描范围

### 前端（TypeScript/TSX）
- `src/**/*.ts`、`src/**/*.tsx`
- 使用 `//` 和 `/* */` 注释语法
- 注意 JSX 中的 `{/* */}` 注释

### 后端（Python）
- `app/**/*.py`
- 使用 `#` 注释语法
- 注意多行字符串 `"""..."""` 不是注释（是 docstring）

## 检查模式

```
正则模式（伪代码）：
- 连续 3+ 行以 // 或 # 开头，且内容看起来是代码（包含 =、()、{}、import、return 等关键字）
- 单行注释掉的 import 语句
- 单行注释掉的变量赋值
- /* */ 块中包含代码语法的内容
```

## 产出

- 删除所有被注释掉的代码
- 保留所有有价值的文档和说明注释
