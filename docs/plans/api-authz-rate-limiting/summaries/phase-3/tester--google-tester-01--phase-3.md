Drove the actual exported `http.get`/`http.stream` with a mocked `fetch` returning 429 JSON:
- **header ABSENT (proxy path) + body `error_details.retry_after=42` → `retryAfter===42`** (the
  core fix: surfaces the server's real N, not the 5s default).
- header PRESENT "30" + body 42 → **30** (header precedence preserved).
- header ABSENT + no body `retry_after` → **default 5**; body `retry_after=0` ignored → **5**.
- fractional body `12.3` → **ceil 13**.
- `ecliptrix:rate-limited` CustomEvent dispatched with the resolved `retryAfter=42`.
- thrown error is `RateLimitError`, `.code==='RATE_LIMITED'`.
- **stream path**: header-less 429 reads body `retry_after=77` too.
- **no auto-retry**: `fetch` called exactly once per 429 in both `request` and `stream` paths.
