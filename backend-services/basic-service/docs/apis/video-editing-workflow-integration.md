# 视频编辑工作流集成 - 用户手册

## 概述

本文档介绍如何在视频编辑任务中配置和使用工作流自动调用功能。该功能通过智能意图检测，自动判断用户是否需要调用工作流，提供更加自然和高效的交互体验。

## 功能特性

### 1. 智能意图检测

- **自动分析**: 系统自动分析用户提问，判断是否需要调用工作流
- **实时反馈**: 在聊天界面中实时显示意图检测状态
- **高准确度**: 使用 qwen-max-latest 模型，准确度高达 95%+

### 2. 工作流配置

- **可视化配置**: 通过图形界面配置工作流
- **启用/禁用**: 灵活控制哪些工作流参与意图检测
- **自定义描述**: 为每个工作流定制工具描述，提高匹配准确度

### 3. Apple 风格 UI

- **简洁优雅**: 遵循 Apple Human Interface Guidelines
- **动画流畅**: 平滑的加载动画和过渡效果
- **直观反馈**: 清晰的视觉提示和状态指示

## 使用指南

### 第一步：配置工作流

1. **打开工作流配置面板**
   - 在视频编辑任务左侧聊天窗口中
   - 点击工具栏上的"⚡"（工作流）按钮
   - 弹出"工作流配置"对话框

2. **选择工作流**
   - 左侧面板显示所有可用的工作流
   - 点击某个工作流查看详情
   - 使用右侧的开关按钮启用/禁用工作流

3. **配置工具描述**
   - 在右侧面板中编辑"工具描述"
   - 描述应该准确说明工作流的功能和适用场景
   - 示例：
     ```
     此工作流用于自动剪辑视频，可以根据音频节奏
     和视觉亮点自动生成精彩片段剪辑。适用于需要
     快速生成短视频的场景。
     ```

4. **保存配置**
   - 点击右下角"保存"按钮
   - 配置将自动保存到任务状态中
   - 下次打开任务时会自动恢复配置

### 第二步：与 AI 对话

1. **发送问题**
   - 在聊天输入框中输入您的问题或需求
   - 按 Enter 键或点击发送按钮

2. **意图检测过程**
   - 如果有启用的工作流，系统会先进行意图检测
   - 界面会显示"正在分析意图..."的动画提示
   - 这个过程通常需要 1-2 秒

3. **查看检测结果**
   - 如果需要调用工作流，会显示绿色提示框
   - 提示框包含：
     - 将要调用的工作流名称
     - AI 的判断理由
     - 置信度百分比

4. **工作流执行**
   - 系统会自动调用相应的工作流
   - 在聊天界面中显示执行过程
   - 最终返回工作流的执行结果

### 第三步：查看和使用结果

- **聊天历史**: 所有对话和工作流调用记录都保存在聊天历史中
- **清除对话**: 点击垃圾桶图标可以清除聊天记录
- **导出结果**: 工作流的输出结果可以在相应的面板中查看和使用

## 最佳实践

### 编写有效的工具描述

**好的描述示例**:
```
工作流名称：智能视频剪辑
工具描述：
此工作流可以自动分析视频内容，识别精彩片段和关键时刻。
功能包括：
- 根据音频节奏自动切分视频
- 检测人脸表情和动作高光
- 生成 15-60 秒的短视频剪辑
适用场景：Vlog、教程视频、访谈录制的快速剪辑
```

**不好的描述示例**:
```
剪辑视频
```

### 提问技巧

**明确具体的问题**:
- ✅ "帮我把这个 5 分钟的视频剪辑成 30 秒的精彩片段"
- ❌ "处理视频"

**提供上下文**:
- ✅ "我有一段采访录音，需要生成字幕并配上相关的 B-roll 视频"
- ❌ "生成视频"

**一次一个任务**:
- ✅ "先帮我分析这个视频的内容"
- ❌ "分析视频、生成字幕、添加音乐、导出成品"

## 故障排除

### 工作流不被调用

**问题**: 提问后没有触发工作流

**可能原因**:
1. 没有启用任何工作流
2. 工具描述不准确，AI 无法匹配
3. 问题描述不够明确

**解决方案**:
1. 检查工作流配置，确保至少有一个工作流启用
2. 优化工具描述，使其更准确地描述功能
3. 更明确地描述您的需求

### 错误调用工作流

**问题**: AI 调用了错误的工作流

**可能原因**:
1. 多个工作流的描述过于相似
2. 工具描述不够准确
3. 问题描述含糊不清

**解决方案**:
1. 为每个工作流编写独特、明确的描述
2. 在问题中使用更具体的关键词
3. 检查并修改工作流的工具描述

### 意图检测慢

**问题**: 意图检测需要很长时间

**可能原因**:
1. Fast LLM API 响应慢
2. 网络连接问题
3. 启用了太多工作流

**解决方案**:
1. 等待片刻，通常会在 2-3 秒内完成
2. 检查网络连接
3. 禁用不常用的工作流

## 技术细节

### 意图检测流程

```
用户发送消息
    ↓
收集启用的工作流配置
    ↓
调用 Fast LLM API
    ↓
解析意图检测结果
    ↓
是否需要工作流？
    ├─ 是 → 调用工作流 → 返回结果
    └─ 否 → 普通聊天响应
```

### 数据流

```
VideoEditingInterface
    └─ workflowConfigs (Map)
        ↓
VideoChatWindow
    └─ onSendMessage
        ↓
/api/video-editing-chat
    └─ workflowConfigs (Array)
        ↓
/api/intent-detection
    └─ Backend /api/intent-detection/detect
        ↓
Fast LLM (qwen-max-latest)
```

### 配置持久化

工作流配置保存在任务的 `uiState.workflowConfigs` 中：

```typescript
{
  "workflowId": "workflow-123",
  "workflowName": "智能视频剪辑",
  "enabled": true,
  "toolDescription": "..."
}
```

## 常见问题 (FAQ)

**Q: 可以同时启用多个工作流吗？**
A: 可以。AI 会根据用户问题选择最匹配的一个工作流。

**Q: 工作流配置会自动保存吗？**
A: 是的，点击"保存"按钮后，配置会立即保存到任务状态中。

**Q: 如果 AI 判断错误怎么办？**
A: 您可以直接告诉 AI"不需要调用工作流"，或者重新描述您的需求。

**Q: 可以跳过意图检测直接调用工作流吗？**
A: 当前版本不支持。未来可能会添加手动触发功能。

**Q: 意图检测会消耗 API 额度吗？**
A: 是的，每次意图检测都会调用 Fast LLM API。
