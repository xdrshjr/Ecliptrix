# Toast 通知效果示例

## 视觉效果说明

本文档展示了单设备登录功能中各种 Toast 通知的效果。

## 1. 会话失效警告 (Warning)

### 触发场景
当用户的账号在另一台设备上登录时，当前设备会显示此通知。

### 效果描述
```
┌─────────────────────────────────────────┐
│  ⚠️  您的账号已在另一台设备上登录          │
│                                         │
│  [==================>      ] 6秒        │
└─────────────────────────────────────────┘
```

**特征：**
- 🟨 黄色/橙色背景
- ⚠️ 警告图标
- ⏱️ 显示6秒
- 📍 位置：右上角
- 🎨 z-index: 9999（最顶层）

### 代码
```typescript
notification.showWarning("您的账号已在另一台设备上登录", 6000);
```

---

## 2. 登录成功提示 (Success)

### 触发场景
用户成功登录后显示。

### 效果描述
```
┌─────────────────────────────────────────┐
│  ✓  欢迎回来，admin！                     │
│                                         │
│  [===============>         ] 3秒        │
└─────────────────────────────────────────┘
```

**特征：**
- 🟩 绿色背景
- ✓ 成功图标
- ⏱️ 显示3秒
- 📍 位置：右上角
- 👤 显示用户名（个性化）

### 代码
```typescript
notification.showSuccess(`欢迎回来，${data.user.username}！`, 3000);
```

---

## 3. 登录失败提示 (Error)

### 触发场景
用户登录失败时显示。

### 效果描述
```
┌─────────────────────────────────────────┐
│  ✕  用户名或密码错误                      │
│                                         │
│  [==============>          ] 4秒        │
└─────────────────────────────────────────┘
```

**特征：**
- 🟥 红色背景
- ✕ 错误图标
- ⏱️ 显示4秒
- 📍 位置：右上角
- 📋 同时在登录模态框内显示

### 代码
```typescript
notification.showError(errorMessage, 4000);
```

## Toast 动画效果

### 进入动画
```
右侧滑入 →
┌─────────────┐
│   Toast     │  ← 淡入效果
└─────────────┘
```

**动画参数：**
- 持续时间：300ms
- 缓动函数：ease-out
- 效果：从右侧滑入 + 淡入

### 退出动画
```
            → 右侧滑出
┌─────────────┐
│   Toast     │  ← 淡出效果
└─────────────┘
```

**动画参数：**
- 持续时间：200ms
- 缓动函数：ease-in
- 效果：向右侧滑出 + 淡出

## 多个 Toast 的堆叠效果

当有多个通知时，它们会垂直堆叠：

```
        右上角
        ↓
┌─────────────────────────┐  ← Toast 1（最新）
│  ✓  登录成功              │
└─────────────────────────┘
        ↓ 间距 8px
┌─────────────────────────┐  ← Toast 2
│  ⚠️  会话即将过期          │
└─────────────────────────┘
        ↓ 间距 8px
┌─────────────────────────┐  ← Toast 3（最旧）
│  ℹ️  系统维护通知          │
└─────────────────────────┘
```

**堆叠规则：**
- 新通知在上方
- 旧通知在下方
- 垂直间距：8px
- 最大宽度：384px (max-w-sm)

## 用户交互

### 手动关闭
用户可以点击关闭按钮提前关闭 Toast：

```
┌─────────────────────────────────┐
│  ✓  欢迎回来，admin！      [×]   │  ← 关闭按钮
└─────────────────────────────────┘
```

### 自动消失
Toast 会在指定时间后自动消失，无需用户操作。

### 悬停暂停（可选）
某些实现支持鼠标悬停时暂停倒计时。

## 可访问性支持

Toast 通知会被屏幕阅读器识别：

```
ARIA 属性：
- role="alert"

- aria-atomic="true"
```

- Toast 可通过 Tab 键聚焦
- 关闭按钮可通过 Enter/Space 触发

## 性能优化

### 重复检测
系统会自动检测并跳过重复的通知：

```typescript
// 如果已存在相同的消息，不会重复显示
const existingToast = prev.find(
  toast => toast.message === message && toast.type === type
);
if (existingToast) {
  return prev; // 跳过
}
```

### 内存管理
Toast 自动清理，不会积累：

```typescript
// Toast 消失后自动从 DOM 中移除
const removeToast = useCallback((id: string) => {
  setToasts(prev => prev.filter(toast => toast.id !== id));
}, []);
```
