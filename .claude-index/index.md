## Project Overview

- **Type:** Electron desktop app (Next.js renderer + local FastAPI service), single monorepo
- **Languages:** TypeScript (~60%), Python (~35%), JavaScript (~5%)
- **Frameworks:** Next.js 15 (App Router) + React 19 + FastAPI + Electron
- **Entry Points:**
  - Frontend: `src/app/page.tsx`, `src/app/layout.tsx`
  - Backend: `backend-services/basic-service/app/main.py` (`run.py`)
  - Desktop: `desktop/main/index.js` (Electron main), `desktop/preload/preload.js`
- **Database:** SQLite via async SQLAlchemy + aiosqlite. No PostgreSQL, no Alembic — the schema is built by `create_all` at startup plus an idempotent ownership `UPDATE`; tests use SQLite in-memory
- **UI:** shadcn/ui (new-york style), Tailwind CSS 3, class-based dark mode
- **State:** React Context (Locale / Notification) + Zustand (`useVideoEditingStore`, `useTimelineStore`)
- **i18n:** English + Chinese in one file (`src/lib/i18n.ts`, ~7.9k lines)
- **Auth:** none. Single local owner, expressed as the constants `LOCAL_OWNER_ID` / `LOCAL_OWNER_NAME` (`app/constants.py`, mirrored in `src/lib/localOwner.ts`). The backend binds to `127.0.0.1` and no route carries an auth dependency
- **Testing:** Vitest (frontend, `vitest.config.ts` + `vitest.integration.config.ts`), pytest (backend, 111 test files)
- **Deployment:** desktop only — `electron-builder` installer; there is no server deployment path
- **Scale:** ~620 non-test TS/TSX source files, ~140 backend Python modules, 103 Next.js API routes, 31 backend routers

### Current Branch Context

Working branch is `feat/remove-user-system`. The desktop-only refactor
(`docs/plans/desktop-only-refactor/spec.md`) **has landed**: the user system,
login, RBAC, global rate limiting, PostgreSQL/Alembic, the web page shell

## Storage Model

- **Primary:** local filesystem under `STORAGE_ROOT` (default `static/uploads`). Static mounts: `/api/storage/files`, `/api/audio/generated`, `/api/audio/subtitles`, `/static/timeline_exports`.
- **Layout:** `static/uploads/{video,audio,images,files}`, `static/video/{composed,thumbnails}`, `static/audio/{generated,subtitles}`, `static/timeline_exports`, `temp/`, `logs/`
- **Cached remote materials:** `STORAGE_ROOT/cached_materials/<source>/<source_id>.<ext>`, tracked in the `cached_materials` table, served through the existing `/api/storage/files` mount. Frontend derives `local_url` as `/api/storage/files/cached_materials/<source>/<basename>`.
- `MATERIAL_DOWNLOAD_MAX_CONCURRENT` (default 4) caps the background download semaphore. ARK/storyboard videos write back via `material_svc.store_external_download_async(..., source='ark', source_id=<task_id>)`.
- No cloud object storage — this is a self-contained local desktop app.

## Shipping

There is no server deployment: Ecliptrix ships as an Electron desktop app, so
"shipping" means building an installer, not provisioning a host.

- `cd desktop && npm run build` — installer (prepare-env -> prepare-frontend -> prepare-backend -> electron-builder)
- `cd desktop && npm run build:dir` — unpacked build, the input to the smoke test
- `node desktop/scripts/smoke-test.js` — end-to-end gate on the packaged app
- Dev stack: `cd desktop && npm run dev` (Electron + backend + Next dev server), or
  `uvicorn app.main:app --host 127.0.0.1 --port 8000` from `backend-services/basic-service/`
  plus `npm run dev` at the repo root for the browser debugging path
